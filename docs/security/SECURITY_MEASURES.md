# GreenPulse Security Measures

## Практическая работа №26
## Внедрение мер безопасности

В рамках практической работы в проект GreenPulse были внедрены базовые меры безопасности.

## Реализованные механизмы

| Мера безопасности | Реализация |
|---|---|
| Аутентификация | Добавлен AuthService для регистрации и входа пользователя |
| Хеширование паролей | Используется PBKDF2-HMAC-SHA256 с солью |
| Проверка пароля | Используется безопасное сравнение через compare_digest |
| Контроль доступа | Добавлен AccessControlService |
| Ограничение доступа к данным | Пользователь видит только свои записи |
| Ошибка доступа | При попытке получить чужую запись возникает AccessDeniedError со статусом 403 |
| Роль администратора | Пользователь с ролью admin может видеть все записи |
| Тестирование безопасности | Добавлен набор тестов tests/test_security.py |

## User Story 1. Защита аккаунта

Как пользователь, я хочу, чтобы никто не мог войти под моим аккаунтом без пароля.

Критерии приемки:
- логин и пароль проверяются при входе;
- пароль не хранится в открытом виде;
- неверный пароль отклоняется.

## User Story 2. Безопасность данных

Как пользователь, я хочу быть уверен, что мои данные доступны только мне.

Критерии приемки:
- записи фильтруются по owner_user_id;
- попытка доступа к чужой записи возвращает ошибку 403;
- администратор имеет расширенный доступ.

## Итог

Базовые меры защиты внедрены и покрыты тестами.
