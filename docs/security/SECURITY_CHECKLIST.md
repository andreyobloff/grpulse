# GreenPulse Security Checklist

## Практическая работа №25
## Анализ безопасности кода

Проект: GreenPulse  
Язык: Python  
Инструмент статического анализа: Bandit

## Чек-лист безопасности

| Проверка | Статус | Комментарий |
|---|---|---|
| Используется ли HTTPS | Не применимо | На текущем этапе API и сетевой слой не реализованы |
| Пароли хранятся в хешированном виде | Не применимо | Модуль авторизации пока отсутствует |
| Есть ли защита от SQL-инъекций | Частично применимо | База данных пока не подключена, риск учтён для будущей реализации |
| Проверяется ли авторизация при доступе к данным | Не применимо | Контроль доступа будет актуален после добавления API |
| Есть ли валидация пользовательского ввода | Выполнено | В проекте реализована валидация данных датчиков |
| Используется ли статический анализ безопасности | Выполнено | Выполнен анализ Bandit |
| Есть ли автоматическая проверка безопасности в CI/CD | Выполнено | Добавлен workflow security.yml |
| Отсутствуют ли hardcoded secrets | Выполнено | В коде не используются токены, пароли или ключи |
| Есть ли контроль некорректных данных | Выполнено | Проверяются диапазоны значений и неизвестные типы сенсоров |
| Есть ли обработка потенциально опасных операций | Требует контроля | В тестах используется subprocess; требуется ограничивать область применения |
