# GreenPulse Agile Board

Для практической работы №23 была создана реальная Agile-доска в GitHub Projects.

Проект: GreenPulse Sprint 1

Используемая структура:
- Backlog
- In Progress
- Review
- Done

Для планирования использованы:
- GitHub Projects;
- GitHub Issues;
- labels;
- milestone;
- story points в описании задач;
- критерии приемки в user stories.
