# Release Notes v1.0.0

Проект: GreenPulse

Версия 1.0.0 является первым стабильным учебным релизом проекта.

В релиз вошли:
- базовая архитектура приложения;
- модуль валидации экологических данных;
- расчёт агрегированных показателей по станциям;
- автоматические тесты;
- CI/CD через GitHub Actions;
- подготовка артефакта развертывания;
- рефакторинг кода и разделение на модули;
- формализация процесса управления версиями.

Структура веток:
- main — стабильная версия проекта;
- develop — ветка разработки и проверки изменений;
- feature/version-management — ветка для настройки процесса версионирования.

Релиз отмечен Git-тегом v1.0.0.
