# GreenPulse Changelog

## [1.0.0] - 2026-05-04

### Добавлено
- Базовая структура проекта GreenPulse.
- Модуль обработки и валидации данных экологического мониторинга.
- Проверка показателей PM2.5, PM10, CO2, температуры, влажности и шума.
- Расчёт статуса качества среды: normal, warning, critical, invalid.
- Автоматический запуск тестов через GitHub Actions.
- Workflow для сборки и подготовки артефакта развертывания.
- Структура проекта после рефакторинга: models.py, services.py, demo_data.py, greenpulse_app.py.

### Изменено
- Код проекта разделён на отдельные модули.
- Улучшена читаемость и поддерживаемость бизнес-логики.
- Добавлена статическая проверка кода с использованием Flake8.

### Проверено
- Запуск приложения.
- Запуск тестов.
- Статический анализ кода.
- Работа веток main, develop и feature/version-management.
